# Blue Wallet Offshore v0.2

## Added
- Direct rear-camera document capture on iPhone and Android.
- Separate camera and Files/PDF controls.
- Automatic optimization of large photographs before IndexedDB storage.
- 25 MB per-file safety limit to reduce storage failures.
- Device storage usage indicator in Settings.
- Online/offline status messages.
- Reliable service-worker update prompt and cache upgrade to v0.2.

## Retained
- Fully offline app shell after Home Screen installation.
- Local IndexedDB document storage.
- PIN/AES encryption when used from HTTPS.
- Backup/restore, expiry tracking, document packs, sea time, vaccines and STCW tools.

## Limitation
OCR libraries still require an internet connection on first use. Existing stored documents and all core wallet functions work offline.
