Quick start

            
    
              
  1. Use + Add for passport, CDC, COC, visas, certificates, medical, yellow fever, contract, and other documents.
    2. 
              
  2. Attach clear scans or PDFs, complete the quality checklist, add notes/tags, then save.
    3. 
              
  3. Set a PIN in Settings before using the wallet on a shared device.
    4. 
              
  4. Run Export Backup after important changes and before device transfer.
    5. 
              
  5. Use Lite for daily wallet use and Full for packs, OCR, logs, QA, and release tools.
    6. 
            

          

          

            

              
LITE

              
Core wallet: add, view, print, download, wallet-wide search, sort, status filter, expiry banner, PIN, backup, and install guidance.

            

            

              
FULL

              
Everything in Lite plus quality checklist, packs, renewal timeline, STCW, sea-time, vaccines, bulk tools, OCR, biometrics, activity log, QA pack, and release readiness.

            

          

          

            
Privacy

            
The wallet is offline-first and local-only. Documents live in this browser's IndexedDB; the app does not upload scans, profile data, notes, or backups to a server.

          

          

            
Appearance

            
Settings include VIBGYOR appearance themes: Violet Tide, Indigo Depth, Ocean Blue, Deep Current, Golden Beacon, Harbor Sunset, and Coral Red, plus Abyssal Night and Aurora Watch animated sea themes. Ocean Blue remains the default stable appearance.

          

        


        

          

            
Managing documents

            
    
              
  • Add - choose document type, title, number, authority, issue/expiry dates, scans, tags, notes, flag-state notes, and manual reminder notes.
    • 
              
  • No Expiry - use for documents that do not expire; they stay out of expiry alerts but remain searchable and printable.
    • 
              
  • Scans - attach JPG, PNG, or PDF files; multiple attachments are supported per document.
    • 
              
  • Quality checklist - mark readable, full page, stamp/signature, front/back, and verified against original.
    • 
              
  • View - open a card to preview, download, print, edit, or delete. On desktop/tablet the viewer gives about 70% of the space to the scan and 30% to quality/version details.
    • 
              
  • Version history - edits are recorded locally so changed title, dates, notes, quality, and scan changes can be reviewed.
    • 
              
  • Duplicates - import and document checks warn about likely duplicate records.
    • 
            

          

          

            
Categories

            
PASSPORT - CDC - COC - VISAS - CERTIFICATES - MEDICAL - YELLOW FEVER - CONTRACT - OTHER.

            
Tabs stay visible in one row without horizontal scrolling. Narrow screens use clear short codes: PPT, CDC, COC, VSA, CRT, MED, YF, CTR, and OTH.

          

          

            
Find documents

            
Search is wallet-wide when a query is entered, so results are not limited to the open category tab. Search covers title, document number, authority/issuer, notes, tags, expiry month/year, and category.

            
Advanced tokens include status:expired, status:expiring, issuer:dg, tag:joining, category:medical, missing-scan, quality:unchecked, risk, and expiry:2026-09. Empty search keeps category browsing normal.

          

          

            
Expiry & reminders

            
Expiry alerts group documents into expired, expiring soon, valid, and no-expiry. Reminder windows default to 183 / 90 / 30 / 7 days and can be edited in Settings. Full mode adds Reminder Center, Renewal Timeline, manual reminder notes, and Calendar .ics export.

Where are files stored?
Only on this device in the browser's IndexedDB. Clearing site data removes them unless you exported a backup.

          
Why won't OCR or biometrics work?
They need a secure context: HTTPS or localhost. Opening the HTML as file:// usually blocks them. OCR also needs its external OCR and PDF libraries to be reachable when you press the OCR button.

          
Lite and Full use the same data?
Yes. One local database; only available controls change. Toggle anytime from the header or Settings.

          
Document has no expiry date?
Enable "No Expiry Date" when adding or editing. It will not appear in expiry alerts but stays in search, summary, backup, and packs.

          
Lost PIN?
The app cannot decrypt locked data without the PIN. Restore from a backup after clearing site data only if you accept resetting the local encrypted store.

          
Category names look cut off?
On narrow screens, compact category codes keep every tab visible in one row.

          
Is anything uploaded online?
By default, no document data is uploaded. OCR libraries may load from CDN only when you run OCR on a secure origin. If you explicitly configure Encrypted Sync Vault, the app uploads only an encrypted full-backup payload to your Supabase vault.

          
Can desktop and mobile sync automatically?
Yes, if you explicitly configure Encrypted Sync Vault in Settings. The app encrypts the full backup on-device before uploading it to Supabase, then another device can pull and decrypt it with the same vault ID and passphrase.

          
Why does search ignore the open category tab?
That is intentional. When you type a query, search becomes wallet-wide. Clear the search box to browse one category tab at a time.

          
How do I know the final build is ready?
Use Full mode -> Release Readiness and Real Device QA Pack, then run the required physical-device checks on iOS Safari, Android Chrome, Windows Chrome, and Windows Edge.
